Déposez ici l'extraction Diakonos

Le fichier suivi_production_JJMMAAAA.xlsx exporté de Diakonos. Tout est calculé à chaque nouveau fichier : il suffit de redéposer l'extraction du jour pour mettre le tableau à jour.

Plusieurs extractions (ex. production + fournitures) : choisissez-les ensemble, ou ajoutez-les ensuite. Une ligne présente dans deux fichiers n'est comptée qu'une fois.

Le fichier est lu sur ce PC : rien n'est envoyé sur internet.

Le plus simple : choisissez une fois le dossier où arrivent les extractions. L'outil y lira tout seul la dernière version à chaque ouverture.
